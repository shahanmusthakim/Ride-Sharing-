# 🚗 Wanna_Go – Ride Sharing System

A console-based Ride Sharing System built with Python, demonstrating the core concepts of Object-Oriented Programming (OOP).

The project simulates a basic ride-sharing platform where riders can request rides, drivers can accept requests, and fares are calculated according to vehicle types.

## ✨ Features

- Rider and Driver Management
- Ride Request System
- Automatic Driver Matching
- Vehicle Management (Car and Bike)
- Automatic Fare Calculation
- Rider and Driver Wallet Management
- Ride Start and End Time Tracking
- Ride Details Display

## 🛠️ Technologies Used

- Python 3
- Object-Oriented Programming
- ABC Module
- Datetime Module

## 🧠 OOP Concepts

| Concept | Implementation |
|---|---|
| Encapsulation | Managing class attributes and methods |
| Inheritance | Rider and Driver inherit from Users |
| Abstraction | Abstract Users and Vehicle classes |
| Polymorphism | Different display_profile() methods |
| Composition | Ride contains a Vehicle object |
| Association | Rider and Driver interact through Ride |
